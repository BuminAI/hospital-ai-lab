AI 프로그램 심사실

직접 만든 AI 업무 프로그램 파일을 올리면, 코드를 자동으로 분석하고 실행해 보안·완성도·사용성·문서화·재사용성을 채점합니다. 업무 효과처럼 코드만으로 알 수 없는 부분만 짧게 묻습니다. 성향이 다른 심사위원 3명이 공개된 규칙대로 각자 100점 만점으로 채점하고, 평균으로 S·A·B·C 등급을 매깁니다.

100점 중 60점은 파일 분석으로 채점AI 호출 없음 · 같은 파일이면 같은 점수분석은 이 브라우저 안에서 진행

제출

지금은 예시 프로그램 '연차 사용일수 계산기' 파일 2개와 답변이 들어가 있습니다. '모두 지우기'를 누르고 심사할 프로그램을 올리세요.

1. 프로그램 파일

완성도 · 편의성 · 문서화 · 확산 · 보안 자동 채점
파일이나 ZIP을 여기에 끌어다 놓으세요 HTML · JS · Apps Script(.gs) · Python · 노트북(.ipynb) · 프롬프트(.txt .md) · 설명서(README) · ZIP 설명서(README.md 등)를 함께 올리면 문서화 점수에 반영됩니다. 파일당 2MB, 최대 200개.

심사 결과

자동 분석 리포트

올린 파일에서 찾은 근거 · 행 번호 포함

파일을 올리면 분석 결과가 여기에 나옵니다.

점수표와 심사 규칙

모든 기준을 공개합니다
  1. 필수요건을 먼저 확인합니다. 파일에서 API 키·비밀번호나 개인정보로 보이는 값이 나오면 보류합니다. 외부 AI 호출이 발견되면 민감정보를 보내지 않는다는 확인이 있어야 합니다.
  2. 영역 6개마다 단계(상·중상·중·하)가 정해지고, 단계별 고정 점수를 더해 100점 만점이 됩니다. 기능 완성도·사용 편의성·문서화·확산 가능성(60점)은 파일 분석으로, 현업 적합성·효과성(40점)은 답변으로 채점합니다.
  3. 세 심사위원은 같은 분석 결과를 보되, 아래 공개된 성향 규칙에 따라 일부 기준을 다르게 적용합니다.
  4. 세 점수의 평균(소수 첫째 자리)으로 등급을 정합니다. 심사위원 간 차이가 15점 이상이면 담당자가 직접 확인한 뒤 확정하세요.

보상 금액은 기관마다 다르므로 직접 입력하세요. 입력값은 이 브라우저에만 저장됩니다.

자동 분석은 문자열 규칙으로 판단하므로 놓치거나 잘못 잡는 경우가 있습니다. 결과는 심사 담당자의 판단을 돕는 근거로 쓰세요.
