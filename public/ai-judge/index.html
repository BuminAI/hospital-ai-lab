AI 프로그램 심사실

만든 프로그램을 올려 주세요. 안전성·신뢰성·사용성·유지보수성·이식성, 열네 가지 눈으로 차분히 읽어 드립니다.

프로그램 올리기

파일이나 ZIP을 여기에 끌어다 놓으세요 HTML(스크립트 포함) · JS · Apps Script(.gs) · Python · 노트북(.ipynb) · ZIP 프로그램 소스 코드만 심사합니다. PDF·워드·엑셀·이미지·설명 문서는 심사 대상이 아니며 점수에도 쓰이지 않습니다. 파일당 2MB, 최대 200개.

연결된 링크도 함께 심사 (선택)

프로그램이 GitHub 저장소나 구글 앱스크립트 웹앱 등과 이어져 있다면 주소를 붙여 넣으세요. 업로드한 파일과 합쳐 하나의 프로그램으로 심사합니다.

    프로그램 이름·제출자 적기 (선택)

    프로그램명·제출자·소속은 기록용이며 점수에는 영향을 주지 않습니다.

    지금은 예시 프로그램 '연차 사용일수 계산기'가 들어 있습니다. '모두 지우기'를 누르고 심사할 프로그램을 올리세요.

    샘플은 연습용입니다. 운영자에게 전송되지 않고 기록에도 남지 않습니다.

    AI를 부르지 않습니다 · 같은 코드는 같은 점수 · 분석은 이 브라우저 안에서

    이렇게 읽어 드립니다

    1. 01올리기

      HTML·JS·Python 등 프로그램 파일이나 ZIP을 올립니다. 문서와 이미지는 대상이 아닙니다.

    2. 02읽기

      코드를 읽고, 가능한 것은 격리된 창에서 실제로 실행해 봅니다. 모든 분석은 이 브라우저 안에서만 이뤄집니다.

    3. 03채점

      코드에서 찾은 사실만으로 14항목, 100점 만점. 같은 코드는 언제나 같은 점수가 나옵니다.

    4. 04안내

      점수와 함께 잘한 점, 다음에 할 일, 근거가 된 줄 번호를 알려 드립니다. 고쳐서 다시 올려 점수가 오르는 것을 확인해 보세요.

    내 점검 기록

    이 브라우저에만 저장됩니다. 고쳐서 다시 올리면 점수가 어떻게 달라지는지 볼 수 있습니다.

      AI 프로그램 심사실 · 채점 규칙은 자유롭게 참고·활용할 수 있습니다.홈으로

      심사 결과

      이 결과는 올린 분의 브라우저에서만 만들어지며, 운영자에게 PDF로 전달되지 않습니다. 'PDF로 저장'을 누르면 인쇄 창이 열립니다. 대상(프린터)을 'PDF로 저장'으로 고르세요.

      올린 파일에서 찾은 근거 · 행 번호 포함

      파일을 올리면 분석 결과가 여기에 나옵니다.

      점수표와 심사 규칙

      모든 기준을 공개합니다
      1. 먼저 심사 대상인지 확인합니다. 실제로 실행되는 코드(HTML은 스크립트, JS·Apps Script·Python 등)가 들어 있는 프로그램이어야 합니다. PDF·문서·이미지, 화면만 있는 HTML은 점수 없이 ‘심사 대상 아님’으로 안내하고 운영자에게 보내지도 않습니다. (AI로 만들었는지는 판별하지 않고, 프로그램인지 여부만 확인합니다.)
      2. 필수요건: 코드에서 API 키·비밀번호나 개인정보로 보이는 값이 나오면 점수와 상관없이 등급을 확정하지 않고 보류합니다.
      3. 14개 항목, 100점 만점: 안전성 35점 · 신뢰성 30점 · 사용성 15점 · 유지보수성 10점 · 이식성 10점. 모든 점수는 올린 코드에서 찾은 사실(파일·줄 번호 근거)로만 계산하며, 항목마다 배점과 점수 규칙을 아래에 모두 공개합니다.
      4. 등급은 점수로 정합니다(S 90점 이상 · A 75점 이상 · B 60점 이상). 다만 실행 오류가 있으면 B 이하로 제한하고, 실제 실행 검사를 하지 못하면 S를 주지 않습니다.
      5. 같은 코드는 언제나 같은 점수와 같은 결과 ID가 나옵니다(코드와 채점 기준 버전으로 만든 지문). 프로그램명·제출자·소속·설명서 등 제출자가 적은 내용은 점수에 전혀 쓰지 않습니다.
      6. 연결한 링크(GitHub·Gist·웹페이지·Apps Script 웹앱)에서 읽어 온 코드는 업로드한 파일과 합쳐서 심사합니다. 링크를 읽지 못하면 그 부분은 점수에 들어가지 않고, 심사 범위가 부분적이므로 S등급은 주지 않습니다. 분석 리포트에 푸는 방법이 나옵니다.

      보상 금액은 기관마다 다르므로 직접 입력하세요. 입력값은 이 브라우저에만 저장됩니다.

      자동 분석은 문자열 규칙으로 판단하므로 놓치거나 잘못 잡는 경우가 있습니다. 결과는 심사 담당자의 판단을 돕는 근거로 쓰세요.
